# Sai Surya Vinay — Personal Portfolio

Welcome to my personal developer portfolio website. This repository showcases my skills, projects, coding profiles, and certificates using a clean HTML/CSS/JavaScript design.

## 🚀 About

This portfolio site is built to highlight my web development skills and programming experience. It includes:

- A modern landing page with a dynamic introduction
- Responsive navigation and contact call-to-action
- Skills, coding profiles, and certificates sections
- External links to GitHub, LinkedIn, email, and resume

## 💡 Features

- Fully responsive and user-friendly layout
- Smooth scrolling navigation
- Animations and interactive UI elements
- Social profile links for networking
- Resume access and certificate collection

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts
- Toastify for notifications

## 📁 Repository Structure

- `index.html` — Main portfolio landing page
- `style.css` — Styling for the portfolio
- `script.js` — JavaScript interactions
- `cetificates.html` — Certificate showcase page
- `coding_profiles.html` — Coding profile links page
- `testing.html` — Additional test/demo page
- `images/` — Project assets and images

## ▶️ Live Preview

Open `index.html` in your browser to view the portfolio.

## 🔧 How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/saisuryavinay/Protofolio.git
   ```
2. Open `index.html` with your browser.
3. Edit the content and images to personalize the portfolio.

## ✨ Customize

Update these files to personalize the project:

- `index.html` — page content and sections
- `style.css` — colors, layout, spacing
- `script.js` — interactive behavior
- `images/` — profile picture and icons
